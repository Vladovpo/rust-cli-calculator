# Правила работы в invoice-keeper

Прочитай до любых действий.

## Проект
- `frontend/` — Nuxt 4 SPA (`ssr: false`), Vue 3, TypeScript. Работаем только тут.
- `backend/` (Go), `nlq/`, `miniapp/` — чужой код. Только читать, никогда не править.
- Источник правды по API — `backend/docs/swagger.json` на ветке `main`. Не добавлять и не вызывать эндпоинты, которых там нет. Ветку `dev1` не читать, не мержить, не сравнивать.

## Проверки (в `frontend/`)
- Зависимости — `npm ci`. Lock-файл не трогать, если задача не про зависимости.
- Быстрые проверки: `npx nuxi typecheck` и `npx eslint app tests`. Для большинства задач их достаточно.
- `npm run test:ui` и `npm run test:contrast` (Playwright) не запускать без отдельной просьбы. Им нужен запущенный `npm run dev`, доступ к живому серверу через devProxy и пароль админа в `UI_ADMIN_PASSWORD`. В облаке этого нет — тесты зависнут на минуты и ничего не покажут.
- Любую команду дольше минуты запускать с `timeout`. Висит — остановить и сказать, не ждать молча.
- В отчёте честно: что упало и с каким выводом, что пропущено и почему.

## Живой сервер
- Ничего туда не записывать: платежи, пользователей, персон. Удаления платежей нет (только остановка) — мусор останется навсегда, плюс может уйти напоминание в Telegram команды.
- Пароли из `SAMPLE_USERS.md` и `.env` никогда не выводить.

## Код
- Стиль: пишем как джун. Комментарии редкие, короткие, строчными, простыми словами, объясняют «зачем». Без жаргона, без длинных тире, без «intentionally / note that».
- Нигде не писать числа и окна rate-limit (UI, комментарии, доки, тесты). Писать «слишком много попыток, попробуйте позже».
- Платежи (демо и живые) — через `usePayments()`, экраны не ходят в `useApi` напрямую.
- Дизайн: токены в `app/assets/css/main.css`, обе темы обязательны, контролы-пилюли, таблицы без рамки, статусы — цветные пилюли `UiStatus`.

## Git
- Коммитить и пушить только по прямой просьбе. Сначала отдельная ветка, не `main`.
- Никаких `Co-Authored-By` и AI-подписей в коммитах и PR.

## Общение
Коротко, по делу, на русском.
